# Machine Learning Optimization & Neural Network Classification

**Course:** CS591 – Advanced Artificial Intelligence  
**Project Type:** Team Project

This project explores foundational machine learning optimization techniques
and a practical neural network application.

Part 1 implements Gradient Descent (GD) and Stochastic Gradient Descent (SGD)
from scratch for polynomial curve fitting. Part 2 uses TensorFlow/Keras to
build and train a feed-forward neural network for Fashion-MNIST clothing
classification.

The project was completed collaboratively as part of CS591.

## Files

- `part1_optimizers.py`
  - Implements polynomial regression using Gradient Descent (GD) and Stochastic Gradient Descent (SGD).
  - Loads data from `Part1_x_y_Values.txt`.
  - Normalizes the input feature values and generates polynomial features for degrees 2, 3, and 4.
  - Runs training for multiple learning rates and saves learning curves to the `plots/` directory.

- `Part1_x_y_Values.txt`
  - A two-column dataset with `X` and `Y` values.
  - Used by `part1_optimizers.py` as the training data source.

- `part2_neural_network.py`
  - Defines and trains a neural network on the Fashion-MNIST dataset.
  - Uses TensorFlow/Keras to build a simple model with one hidden layer and a softmax output layer.
  - Trains for 15 epochs and evaluates test accuracy.
  - Saves the training accuracy plot to `NN_accuracy.png`.

- `Project 3 Report.pdf`
  - Project report document (not generated by these scripts).

## Requirements

- Python 3.x
- NumPy
- Matplotlib
- TensorFlow (for `part2_neural_network.py`)

Install dependencies with pip:

```bash
pip install numpy matplotlib tensorflow
```

## Usage

### Part 1: Optimizer visualization

Run:

```bash
python part1_optimizers.py
```

This script creates a `plots/` folder (if it does not exist) and saves plot images for each experiment.

### Part 2: Neural network training

Run:

```bash
python part2_neural_network.py
```

This script trains a neural network on Fashion-MNIST, prints training progress, evaluates test accuracy, and saves the accuracy plot as `NN_accuracy.png`.

## Output

- `plots/` directory containing visualization images from `part1_optimizers.py`.
- `NN_accuracy.png` generated by `part2_neural_network.py`.

## Notes

- `part1_optimizers.py` includes both batch GD and SGD implementations, along with a plotting helper to visualize the fit across epochs.
- `part2_neural_network.py` uses a simple fully connected architecture suitable for introductory experiments on Fashion-MNIST.
